MapMind Application

Tech Stack: JavaScript, HTML, CSS, Backend Framework (Node.js/Express), PostgreSQL, API

Description:
Developed an interactive world map web application that allows users to create personalized tabs and visually track countries they identify on the map. Users can name countries, and each correctly named country is highlighted in a user-selected color on the world map. The application dynamically stores user data, country progress, and visual preferences in a database, enabling flexible and personalized exploration.

    Key Highlights:
  • User-created tabs to manage multiple mapping sessions
  • Country name validation and visual highlighting upon correct entry
  • Custom color assignment per user or tab for country highlights
  • Persistent storage of user progress, named countries, and statistics
  • Dynamic tracking of total countries identified per user
  • Full CRUD functionality for user tabs (create/delete/update)
